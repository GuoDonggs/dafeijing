修好被漏掉的 Win32 定义：电脑操控一直是半瘫的

审查时用 pyflakes 扫出 windows.py 里 _PS_UTF8 / _INPUT / _KEYBDINPUT /
_INPUTUNION 四个名字未定义 —— 这些是当初把 tools.py 拆成 tools/ 包时漏掉的，
后果比看起来严重：

- _ps() 里的 except 把 NameError 一起吞了，于是**永远返回空串**。
  依赖它的工具全部静默失效：音量、媒体控制、截屏、剪贴板、锁屏、电源、
  执行命令、系统信息，以及这次新加的窗口/进程工具。界面上看起来"执行成功"，
  实际什么都没发生 —— 这种失败最难查。
- type_text / press_keys 直接抛 NameError，打字和快捷键完全不能用。

补回这四段定义之后实测：
  _ps 取桌面 -> D:\桌面
  system_info -> CPU 占用百分之1
  list_processes -> 最占内存的进程：node 占 548 MB，dwm 占 357 MB
  list_windows -> 打开着 9 个窗口
  type_text / press_keys 不再抛异常

顺手：
- console.py 用了 re.split 却没 import re（网页版把唤醒词按逗号填的时候会炸）；
- webui.py / apps.py 去掉没用到的 import；
- test_pipeline 的确认回放也加上重试（和上一处同样的原因：VITS 合成带随机噪声，
  "识别器单独读得对"不等于"喂进状态机还读得对"）。连跑三次稳定通过。

pyflakes 全项目干净（除有意的再导出与探测式导入）。
测试：236 项 + selftest 10 项全部通过，打包版已重建验证。
